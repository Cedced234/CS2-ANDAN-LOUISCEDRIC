
# Travel Fare Calculator

## Description
This program calculates the total travel fare based on the passenger's travel distance and number of passengers.

## Version 1 – Original code without input validation
- Input: Passenger name, travel distance in kilometers, and number of passengers.
- Process: Multiplies the distance by the fare rate of PHP 14 per kilometer and the number of passengers.
- Output: Displays the passenger's name and total fare in Philippine pesos.
- Validation: Does not include input validation.

## Version 2 – Code with input validation
- Input: Accepts the passenger's name, travel distance in kilometers, and number of passengers.
- Process: Validates the inputs and calculates the total fare using PHP 14 per kilometer multiplied by the distance and number of passengers.
- Output: Displays the passenger's name and total fare in Philippine pesos.
- Validation: Checks that the passenger's name is not empty, the distance is greater than 0, and the number of passengers is a positive whole number. Displays error messages and allows invalid inputs to be entered again.
