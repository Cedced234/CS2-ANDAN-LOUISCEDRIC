
# Travel Fare Calculator

## Description
This program calculates the total travel fare based on the passenger's travel distance and number of passengers.

## Version 1 – Original code without input validation
- Input: Passenger name, travel distance in kilometers, and number of passengers.
- Process: Multiplies the distance by the fare rate of PHP 14 per kilometer and the number of passengers.
- Output: Displays the passenger's name and total fare in Philippine pesos.
- Validation: Does not include input validation.
